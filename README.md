# miniguia-estudos-notebooklm
**Contexto e Objetivos:** 
Este repositório reúne meus estudos sobre o BABOK (Business Analysis Body of Knowledge) utilizando o NotebookLM como ferramenta de apoio para aprendizado, organização de conhecimento e geração de insights.
O objetivo deste material é:
- Consolidar o entendimento das áreas de conhecimento do BABOK
- Aplicar conceitos de análise de negócios em contextos práticos
- Estruturar um repositório reutilizável para consultas futuras
- Explorar o uso de IA (NotebookLM) como suporte ao aprendizado técnico
